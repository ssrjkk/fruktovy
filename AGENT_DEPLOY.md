# Инструкция для агента: деплой витрины «Фруктовый дворец»

Документ описывает, в каком состоянии лежит репозиторий, что нельзя ломать и как выложить
изменения в прод. Боевой адрес: `https://ssrjkk.github.io/fruktovy/`, репозиторий
`ssrjkk/fruktovy`, ветка деплоя `main`.

## 1. Архитектура и что реализовано (НЕ ЛОМАТЬ)

Весь фронтенд живёт в одном production-файле `index.html` — HTML, CSS, скрипты и данные
25 позиций. Сборки нет: нет `tools/build.py`, нет Pillow/QuickJS, нет `css/`, `js/`, `src/`,
`dist/`, нет service worker. Фото, шрифты, иконки и превью закоммичены в `assets/`.

Темы (`data-theme`, ключ `fd.theme`), пять палитр одного и того же сайта:

- `market` — «Живой рынок», полосатый тент-навес, лён `#FAF5EC`, кедр `#8C5E3C`, доска `#1D2622`;
- `light` — «Светлая витрина»;
- `fig` — «Инжир и золото»;
- `emerald` — «Изумруд и пергамент»;
- `night` — «Ночной базар».

Карточки 2D и 3D (`data-cards`, ключ `fd.cardMode`): переключатель в панели каталога,
автоматический переход в 2D на тач-экранах (`pointer: coarse`) и при
`prefers-reduced-motion: reduce`; делегированный движок `init3DInteractions()` работает
только через `transform`/`opacity` внутри `requestAnimationFrame`, в покое `will-change`
снимается.

Интерактивный 3D-ящик (`#builder`): 4 сценария, выбор размера на 3 / 5 / 7 позиций,
пересборка, поворот курсором и перетаскиванием, добавление всего ящика в пакет в один клик.

Каталог (`PRODUCTS`, 25 позиций): локальные кадры `assets/img/<id>-<w>x<h>.jpg` без дублей
между позициями, однострочные описания вкуса `desc`, цены в рублях, зачёркнутые старые цены
на хитах, вес, шесть рядов прилавка, режимы «Рядами»/«Сеткой», поиск по `/`, сортировка,
фильтр «Только в сезоне», избранное, «Недавно смотрели».

Паттерн Baymard в карточке: нажатие `+ В пакет` превращает кнопку в строчный степпер
`− [ input type="number" ] +` высотой 44px; число можно ввести с клавиатуры, границы 1..30.
Сдвиг макета нулевой, потому что высота строки зафиксирована до и после.

Быстрый просмотр (`#peekDialog`): три ракурса, шкала сезонности по 12 месяцам, блок
«Часто берут вместе».

Пакет и заказ: выдвижная корзина (`#cartDialog`) со шкалой бесплатной доставки от 2 500 ₽,
самовывоз 0 ₽ / курьер 250 ₽, сворачиваемым промокодом (`Есть промокод?` → `РЫНОК10` −10 %,
`ПРИВЕТ` −200 ₽), шерингом состава через `#cart=...`, повтором прошлого заказа, Undo-тостами.
Оформление (`#checkoutDialog`) с явной маркировкой `(обязательно)` / `(необязательно)` и
тремя способами: СБП (QR-код, демонстрационный), банковская карта (поля демонстрационные,
данные никуда не отправляются), оплата при получении. Эквайринг не подключён — заявка
уходит продавцу, счёт приходит в Telegram. История чеков (`#ordersDialog`) в localStorage
под ключом `fd.orders.v12`, любой заказ повторяется в один клик.

Мессенджеры и чат: Telegram, MAX, WhatsApp и VK ведут на `https://t.me/ssrjkk`; встроенный чат
с продавцом — `#storeChatWidget`. Ссылаются наружу три адреса: `t.me/ssrjkk`, карточка и маршрут
в Яндекс Картах и два `tel:` на номера лавки; запросов наружу при загрузке страницы нет.

SEO и Zero-CLS: один `h1`, один `header`, один `nav`, один `main`; Open Graph и Twitter Card
на локальный `assets/og.png`; JSON-LD `GroceryStore` с адресом, телефоном, часами работы и
`sameAs` на карточку организации в Яндекс Картах; `FAQPage` синхронизирован с видимым FAQ
знак в знак. Самостоятельно проставленный `aggregateRating` в JSON-LD отсутствует: поисковые
системы не принимают рейтинг сторонней площадки на сайте самой организации, поэтому оценка
«4,7 · 39 оценок · 22 отзыва» остаётся видимой в ссылке на карточку — числа сверены с самой
карточкой 22 ноября 2026 года.
`scrollbar-gutter: stable`, `content-visibility`, заранее закадрированные изображения с
`width`/`height`.

Безопасность и приватность: в `<head>` стоит CSP (`default-src 'self'`, `img-src 'self' data:`,
`frame-src https://yandex.ru`, `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`).
Трекеров, сторонних скриптов, шрифтов с чужих CDN и обращений к Pexels в странице нет; единственное
внешнее встраивание — интерактивная Яндекс Карта, которая грузится по клику «Показать на карте».

Дополнительно: `404.html` для Pages, `assets/CREDITS.txt` с лицензиями, кнопка
`Скачать ZIP-архив проекта` в подвале — она запрашивает у сервера десять файлов релиза и
пакует их собственным STORE-писцом, поэтому в архиве лежит ровно то, что задеплоено.
CLI-эквивалент: `python make_zip.py` (флаг `--with-assets` добавляет фото и шрифты).

## 3. Пошаговый алгоритм

### Шаг 1. Зафиксировать состояние

```bash
git status
git switch -c backup/legacy-site      # или легковесный тег:
git tag backup/fruktovy-2026-11-22 && git push origin backup/fruktovy-2026-11-22
```

`main` до конца работы не трогать, пока проверки не зелёные.

### Шаг 2. Править контент в одном месте

Цены, позиции, промокоды, пороги доставки — `index.html` (`PRODUCTS`, `PROMOS`, константы
доставки). При добавлении позиции нужны все размеры кадра, которые запрашивает код:
120x120, 140x140, 200x200, 240x180, 640x480, 900x675, 1200x900. Гейт проверяет наличие
каждого файла, поэтому неполный набор не пройдёт.

### Шаг 3. Смена адреса

При переезде на свой домен заменить origin в `index.html` (canonical, `og:url`, JSON-LD
`@id` и `url`), `robots.txt` (`Sitemap:`) и `sitemap.xml` (`<loc>`), положить `CNAME`,
обновить `start_url`/`scope` в манифесте. `scripts/gate.mjs` сверяет все три файла на один
origin и не пропустит расхождение.

### Шаг 4. Обязательные проверки перед коммитом

```bash
node scripts/gate.mjs                                  # Green обязательен
node -e "const fs=require('fs');const s=fs.readFileSync('index.html','utf8');
  [...s.matchAll(/<script(?![^>]*ld\\+json)[^>]*>([\\s\\S]*?)<\\/script>/g)]
  .forEach((m,i)=>fs.writeFileSync('_s'+i+'.js',m[1]));" && node --check _s0.js && node --check _s1.js
rm -f _s0.js _s1.js                                    # инлайновые скрипты страницы без синтаксических ошибок
python -m http.server 8080 &
```

В браузере, а не глазами по диффу:

1. Консоль — 0 ошибок и 0 сообщений CSP.
2. Горизонтального скролла нет на 320, 360, 390, 414 и 1440px; на тач-эмуляции основные
   контролы не меньше 44px по короткой стороне, на мыши — не меньше 24px (WCAG 2.5.8).
3. Все пять тем: переключить, проверить читаемость кнопок и мела на доске.
4. `+ В пакет` в карточке → степпер, ввести число `7` с клавиатуры → сумма в корзине
   пересчиталась, макет не прыгнул.
5. Промокод: `Есть промокод?` разворачивается, `РЫНОК10` даёт −10 %, `ПРИВЕТ` −200 ₽.
6. Заявка: имя и телефон обязательны, адрес обязателен при курьере, после отправки
   появляется номер `#ФД-XXXX`, заказ попадает в историю, повтор заказа работает.
7. Чат с продавцом открывается, быстрый вопрос даёт ответ, ссылка ведёт в `@ssrjkk`.
8. `3D карточки` / `2D` переключаются и запоминаются; на тач-эмуляции стартует 2D.
9. Кнопка `Скачать ZIP-архив проекта` отдаёт архив, который распаковывается без ошибок и
   содержит десять файлов.
10. Поиск по `/`, «Только в сезоне», избранное, «Недавно смотрели», галерея с лайтбоксом,
    печать страницы.

### Шаг 5. Коммит и публикация

```bash
git add index.html robots.txt sitemap.xml manifest.webmanifest 404.html \
        README.md AGENT_DEPLOY.md NEXT_AGENT_PROMPT.md make_zip.py \
        scripts/gate.mjs assets .github docs
git commit -m "feat: storefront rebuild — local assets, CSP, static gate, honest checkout copy"
git push origin HEAD:main
```

Push в `main` запускает workflow `Deploy to GitHub Pages`: `quality` (secret scan,
`node --check` по скриптам страницы, `node scripts/gate.mjs`) → `deploy` → Pages.
Следить: `gh run watch` или Actions на GitHub. Откат — реvert коммита, история сохранена,
`backup/*` остаётся доступной.

### Шаг 6. Если попросили настоящий магазин

Вынести `PRODUCTS` в `products.json` с валидатором схемы (уникальные кадры, цены больше
нуля, отсортированные месяцы), подключить API-эндпоинты и эквайринг — не трогая визуальные
токены, геометрию карточек и высоту степпера. Сначала серверная часть и тесты, потом
копирайт про оплату в FAQ и бегущей строке: сайт не должен обещать приём денег раньше, чем
он их принимает.

## 4. Известные границы

- Заявки хранятся в localStorage браузера покупателя, сервера заказов нет.
- Оплата демонстрационная: QR рисуется на месте, тестовая карта никуда не отправляется.
- Цены и режим работы — ручные данные; расхождение с прилавком правится здесь же.
- Гейт статический: он считает контраст по токенам и проверяет пути файлов, но не заменяет
  осмотр живого рендера (Шаг 4).
